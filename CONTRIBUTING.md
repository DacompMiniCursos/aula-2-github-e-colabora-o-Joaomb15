### Obrigado por contribuir com esse projeto
## Como contribuir:
* Faça um fork do repositório 
* Crie um Branch para sua ideia:
~~~
git switch -c feature/nome-da-sua-feature
~~~
* Faça suas alterações e commit:
~~~
git commit -m feat:sua-feature
~~~
* Envie para seu fork com:
~~~
git push
~~~
* Faça um pull request, explicando detalhadamente cada alteração e funcionalidade adicionada.
